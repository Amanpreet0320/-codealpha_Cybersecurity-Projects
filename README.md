# CodeAlpha Cybersecurity Projects

Cybersecurity projects completed during my CodeAlpha internship.

## Projects

### Task 1 – Basic Network Sniffer

A Python-based network packet sniffer built using Scapy.

**How it works:**
- Captures network packets.
- Inspects packet information and protocols.
- Displays source and destination details.
- Helps understand basic network traffic analysis.

### Task 3 – Secure Coding Review

A Java-based secure coding project focused on identifying and improving common security weaknesses.

**How it works:**
- Reviews application authentication and password handling.
- Applies secure password practices.
- Improves authentication and input validation.
- Includes security-focused testing.

### Task 4 – Network Intrusion Detection System

A basic Network Intrusion Detection System (NIDS) using Suricata.

**How it works:**
- Generates controlled network traffic using Python and Scapy.
- Saves the traffic as a PCAP file.
- Uses Suricata to analyze the captured traffic.
- Uses custom ICMP and HTTP detection rules.
- Reviews detected events using logs, EVE JSON, and statistics.
